Trabajo Práctico N° 1 – Git y Docker

Sobre este proyecto

Sitio web estático creado con HTML y CSS, versionado con Git y empaquetado en un contenedor Docker con Nginx.

Herramientas utilizadas

  • HTML5 y CSS3: estructura y estilos del sitio.
  • Git y GitHub: control de versiones y repositorio remoto.
  • Docker y Nginx: contenedorización y servidor web.
